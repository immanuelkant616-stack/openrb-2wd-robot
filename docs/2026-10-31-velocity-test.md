# 2026-10-31 — 두 모터 속도 제어 실습

[프로젝트 README](../README.md) · [실행 코드](../firmware/two_motor_velocity_test/two_motor_velocity_test.ino) · [명령별 영상](media/2026-10-31/README.md)

## 목표와 진행

작은 각도로 이동하고 복귀하는 위치 제어 실습 다음으로, 바퀴 구동에 필요한 속도 제어 모드를 시험했습니다. 각 모터의 양방향 회전을 따로 확인한 뒤 자동차의 전진·후진·좌우 회전에 사용할 명령 조합을 실행하고 촬영했습니다. 작성자는 안내된 실습을 모두 완료했다고 보고했고, 명령별 영상 9편을 제공했습니다.

이 날짜는 이번 결과를 정리한 기록일입니다. 실제 차체 주행 단계는 아직 진행하지 않았습니다.

## 장비와 코드 설정

| 항목 | 기록 |
| --- | --- |
| 보드·모터 | OpenRB-150 × 1, XL330-M288-T × 2 |
| 모터 주소·모델 | ID 1·2, Model 1200 |
| 통신 | 시리얼 모니터 115200 baud, 모터 57600bps, Protocol 2.0 |
| 환경 | 영상에 Ubuntu와 Arduino IDE 표시. 모니터의 보드 포트 `/dev/ttyACM0` |
| 기구·전원 | 바퀴·차체 없이 책상 위 모터 시험, USB 연결 |
| 제어 모드 | 속도 제어. 영상의 `velocity mode` 안내 확인 |
| 목표 속도 | raw ±35, 약 ±8rpm에 해당하는 설정. 실제 속도 측정은 미실시 |
| 종료 | 코드의 2000ms 제한과 토크 해제 요청 |
| 추가 설정 | 출력 raw 120 이하, 모터당 전류 200mA·합계 300mA 감시, Bus Watchdog 500ms |

마지막 행은 코드 설정입니다. 전류 임계치 초과나 통신 단절 상황을 실제로 만들어 통과했다는 결과는 아닙니다. IDE·보드 패키지·라이브러리의 실제 설치 버전은 다음 기록에서 보완합니다.

[영상 목록에서 각 파일을 내려받을 수 있습니다.](media/2026-10-31/README.md) 입력 화면과 모터 촬영을 함께 보관했습니다. 일부 영상은 초점·촬영 시점 때문에 전송 직후부터 종료까지의 로그와 움직임이 한 화면에 모두 잡히지는 않습니다.

## 확인한 내용

- 작성자가 개별 양방향 회전과 자동차 조작 명령 실습 완료를 보고했습니다.
- 영상에 각 입력 문자, 모터 축의 움직임과 연결 상태가 기록되어 있습니다.
- `p` 영상에는 ID 1·2 모두 `OK / Model=1200 / velocity mode / torque OFF`와 명령 안내가 표시됩니다.
- 일부 영상의 시리얼 화면에서 `RUN 2s`, `AUTO_STOP: 2 seconds elapsed.`, `TORQUE_OFF_CONFIRMED` 안내를 판독할 수 있습니다. 이는 프로그램의 종료·응답 확인 출력이며 독립적인 정지 시간 측정값은 아닙니다.

## 이번 기록의 범위

`w`·`x`·`a`·`d`는 자동차 조작을 위한 모터 조합입니다. 모터를 차체에 장착하지 않았으므로 실제 전진·후진·좌우 회전을 확인한 것으로 표현하지 않습니다. 조립 후 좌우 장착 방향과 전진 부호를 다시 확인합니다.

또한, 이번 9편 중 05번은 `s` 중단이 아니라 **`p` 연결 확인** 영상입니다. 구동 중 `s`를 입력했을 때의 반응과 `STOP: user command.` 출력을 판독할 수 있는 별도 기록은 추가할 예정입니다. 회전각·실제 rpm·반복 성공률·제동 성능도 측정하지 않았습니다.
