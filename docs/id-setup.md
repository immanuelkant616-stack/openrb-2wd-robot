# 새 두 번째 모터의 ID 설정

[실행 안내로 돌아가기](setup.md)

**현재 장비는 ID 1·2가 이미 확인되었다. 이 절차를 반복할 필요는 없다.** 아래는 새 모터를 추가하거나 설정을 다시 구성할 때 사용하는 도구의 사용법이다.

## 전제

사용 파일은 [set_second_motor_id.ino](../firmware/set_second_motor_id/set_second_motor_id.ino)다. 모터를 회전시키는 명령은 보내지 않지만, `c`를 입력하면 모터에 저장되는 ID를 변경한다.

**반드시 ID를 변경할 두 번째 모터 한 개만 연결한다.** 같은 ID를 가진 모터 여러 개는 검색 결과만으로 개수를 구분할 수 없다. `FOUND`가 한 줄이라는 이유만으로 모터가 한 개라고 판단하지 않는다. 단자 위치로 같은 ID의 모터를 선택할 수도 없다.

분리가 어렵다면 무리하게 당기거나 두 개가 연결된 상태로 변경 명령을 보내지 않는다. 먼저 전원을 끄고 연결 상태를 정리한다.

첫 모터 커넥터의 분리가 어려워 기존 케이블을 유지하는 대안을 모색했던 과정은 [커넥터 문제 해결 기록](troubleshooting.md#5-커넥터가-잘-빠지지-않음)에 정리했다. 아래 단일 모터용 도구와 임시 ID를 이용한 대안은 서로 다른 절차다.

## 사용 순서

1. 전원을 끄고 두 번째 모터만 OpenRB-150에 연결한다.
2. 위 파일을 Arduino IDE로 열고, 보드와 포트를 선택해 `→` 업로드한다.
3. 시리얼 모니터를 115200 baud로 열고 아래 문구를 확인한다.

```text
ID SETUP: second motor ONLY | p: find ID | c: set ID to 2
```

4. `p`와 Enter를 보내 응답한 주소와 모델 번호를 확인한다. 이 도구는 57600 bps에서만 검색한다.
5. 물리적으로 모터 한 개만 연결되어 있고 모델 번호가 1200인지 확인한 뒤, `c`와 Enter로 ID를 2로 변경한다.
6. 성공 메시지 또는 이미 ID 2라는 메시지를 확인한다. `p`를 다시 보내 ID 2의 응답을 확인한다.
7. 전원을 끈 뒤 ID 1인 첫 번째 모터와 함께 연결한다.
8. [주 실행 코드](../firmware/two_motor_usb_test/two_motor_usb_test.ino)를 다시 업로드한다. 프로그램을 바꿔도 모터 내부에 저장된 ID는 유지된다.

이 도구는 첫 번째 모터의 ID를 1로 바꾸는 기능이나 다른 통신속도를 자동으로 찾는 기능을 포함하지 않는다. ID 변경 명령은 실습 대화에서 안내했으나, 실제 변경 과정 전체의 원본 로그는 남아 있지 않다. 보관된 증거는 [최종 ID 1·2 검색 결과](../logs/id-scan-observed.txt)다.
