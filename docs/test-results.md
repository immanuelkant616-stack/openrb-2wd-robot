## 다음에 남길 기록

1. 실제 환경의 OS·IDE·보드 패키지·라이브러리 버전을 적습니다.
2. [기록 양식](../logs/test-session-template.txt)을 복사해 실제 수행 날짜와 스케치 이름을 씁니다.
3. 속도 제어의 `p` → `1` → `3` → `2` → `4` → `w` → `x` → `a` → `d`를 한 번씩 실행하고 전체 출력을 저장합니다.
4. 별도 구동 중 `s`를 입력해 입력 시점·출력·실제 움직임을 함께 기록합니다.
5. 같은 조건을 정해 반복한 뒤 성공·실패 횟수와 실제 측정값만 기록합니다.

부품·전원·코드를 바꾸면 별도 조건으로 기록합니다. 업로드된 파일 수를 반복 성공 횟수로 해석하지 않습니다.
