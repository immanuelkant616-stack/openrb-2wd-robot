## 초기 실습 영상

[모터 제어 실습 영상 보기](motor-control-demo.mp4)

시리얼 모니터와 연결한 두 모터를 촬영한 약 18초의 실습 기록이다. 촬영 원음이 작아 전체 음량을 보정했으며 주변 소리도 함께 커질 수 있다.

| 항목 | 내용 |
| --- | --- |
| 파일 | `motor-control-demo.mp4` |
| 원본 용량 | 31.80MB |
| 업로드 용량 | 4.37MB, 약 86% 감소 |
| 영상 형식 | MP4, H.264, 1280 × 720, 30fps |
| 음성 형식 | 촬영 원음 음량 보정, AAC 128kbps |
| 편집 범위 | 전체 분량·재생 속도를 유지하고 압축과 음량 보정 적용 |

이 영상은 실습 기록으로 보관한다. 회전각, 복귀 오차, 반복 성공률, 중단 명령의 결과는 별도 시험에서 기록한다.

## 초기 위치 제어에서 추가할 자료

초기 위치 제어 실습 영상 한 편을 보관한다. 속도 제어의 최신 영상 9편과 별개로, 아래는 초기 스케치의 명령별 근거를 더 보완할 경우의 촬영 계획이다.

| 저장할 파일명 | 촬영 내용 |
| --- | --- |
| `individual-control.mp4` | `1`, `2`를 각각 입력했을 때의 움직임 |
| `both-control.mp4` | `b` 입력부터 두 모터 작동·자동 종료까지 |
| `serial-stop.mp4` | 별도로 진행한 `s` 중단 시험 |

영상은 입력하는 문자와 실제 모터가 함께 보이도록 촬영한다. 목표 각도나 성공률을 측정하지 않았다면 영상 설명에도 측정 성능처럼 적지 않는다.

`both-control.mp4`를 이 폴더에 실제로 업로드한 **뒤에** 최상위 README에 아래 링크를 추가한다.

```markdown
[두 모터 함께 구동한 영상](docs/media/both-control.mp4)
```

브라우저 업로드에는 파일당 25MiB 제한이 있다. 큰 영상은 짧게 편집하거나 외부에 올린 실제 영상 주소를 README에 넣는다.
