# 다음 개발 단계

[README로 돌아가기](../README.md)

| 단계 | 할 일 | 완료 기준 | 상태 |
| --- | --- | --- | --- |
| 1 | 두 모터 개별·동시 위치 제어 | 두 ID 응답, 각 모터 작동, `b` 동작과 자동 종료 확인 | 완료 |
| 2 | 현재 결과의 증거 보완 | 사진·실습 영상 확보. 명령별 영상과 `s` 중단·반복 시험 로그 보완 | 진행 중 |
| 3 | 한 모터의 연속 회전 | 저속 회전 → 정지 → 반대 방향 회전 확인 | 예정 |
| 4 | 두 모터의 주행 명령 | 좌우 바퀴 장착 방향에 맞춰 전진·후진·회전 명령 정의 | 예정 |
| 5 | 차체·바퀴·전원 구성 | 두 구동 바퀴와 보조 바퀴를 장착하고 실제 주행 확인 | 예정 |
| 6 | 스마트폰 조종 | 무선 방식을 정하고 전진·후진·회전·정지 구현 | 예정 |

연결·통신 확인 사진과 [모터 제어 실습 영상](media/motor-control-demo.mp4)을 등록했다. 명령별 시험 출력, 중단 결과와 반복 성공률은 다음 기록에서 보완한다.

연속 회전 단계에서 제어 모드와 전원 조건을 다시 검토한다. 현재 위치 제어에서 사용한 전류 설정이 다른 모드에서도 동일하게 적용된다고 가정하지 않는다.

다음 코드를 만들기 전 현재 구동 파일을 기준 버전으로 보관한다. 새 기능은 별도 스케치 폴더로 만들고, 시험을 통과한 뒤 README의 구현 상태를 갱신한다. 이후 목표 도달 판정, 중단 응답, 통신 실패 처리도 실제 로그를 바탕으로 개선한다.
