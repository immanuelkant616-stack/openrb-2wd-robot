## 차체 조립 후 확인할 것

- ID 1을 왼쪽, ID 2를 오른쪽으로 배치하고 각 바퀴의 전진 방향 확인
- 바퀴를 띄워 코드의 `LEFT_FORWARD_SIGN`, `RIGHT_FORWARD_SIGN` 조정
- 외부 전원·고정 상태를 확인한 뒤 짧은 직진·후진·회전 시험
- 실제 이동 거리·회전각과 반복 횟수를 기록할 방법 마련
